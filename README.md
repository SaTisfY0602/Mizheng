# 商用密码辅助测评工具：三人协作基线

此仓库当前保存最小闭环的**共享契约、样例和接口测试**；解析器、判定器、工作台和独立核验器仍需按契约实现。仓库中的 JSON 摘要与核验结果是接口示意，不是真实材料的测评结果。

开始开发前先读：

1. [开发协作与代码规范.md](开发协作与代码规范.md)：三人的模块边界、共享类和接口变更规则。
2. [技术栈与版本管理方案.md](技术栈与版本管理方案.md)：推荐技术栈和版本管理办法，目前为建议稿。
3. [共享类](mvp_contracts/models.py)、[接口](mvp_contracts/interfaces.py)和[两组对接样例](examples/contracts/0.2.0-mvp/)：实际编码依据。
4. [9 月 28 日对接会交付清单](9月28日对接会交付清单.md)：会前每人的最小交付、依赖与会议验收。

使用 Python 3.12 与 `requirements-contracts.txt` 中的 Pydantic v2。在项目根目录运行接口测试：

```text
py -3.12 -m unittest discover -s tests -v
```

每人从 `main` 建短期分支。公开字段或接口改变时，同一次提交更新共享类、样例、测试和协作规范，并请另外两人复核。不要把私钥、导入的原始材料、运行数据库或生成报告提交到仓库。
